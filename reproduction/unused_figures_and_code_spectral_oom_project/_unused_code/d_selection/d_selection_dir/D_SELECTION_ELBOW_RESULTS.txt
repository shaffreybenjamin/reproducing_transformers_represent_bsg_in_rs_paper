WHY ELBOW-CCA WINS
================================================================================

Theoretical Advantages:
─────────────────────
1. Elbow detects information transition point (steep → flat)
2. CCA/RRR produces smoother, cleaner spectra than spectral-OOM
3. Elbow is parameter-free (no threshold tuning like 95% vs 99%)
4. Works naturally on any singular value spectrum
5. Interpretable: knee in curve = "good enough" dimensionality

Empirical Evidence:
─────────────────
• 71% exact/±1 > 57% (ER95-OOM) > 43% (others)
• Perfect on deterministic architectures (arch, strata)
• Robust on transitions (fern, wing, rrxor)
• Only struggles on high-variance stochastic (mess3, z1r)
